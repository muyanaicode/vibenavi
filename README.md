# vibenavi

同心圆分类导航：左侧竖向分类栏，悬停展开第一层同心圆，再悬停展开第二层，点击类目全屏展示内容。

纯 HTML/CSS/JS，无构建、无依赖。

- 规模：11 个分类 / 48 个子类 / 355 个真实站点（国内与海外，全部真实官网）
- 交互：悬停展开、点击全屏（从点击位置圆形展开）、触屏两段点击、Esc 关闭、深色模式、`prefers-reduced-motion`
- 搜索：右上角全站搜索，按站点名 / 简介 / 类型匹配，回车直达
- 圆环：第三层超过 8 个时收成「更多 N 个」节点，点开为全屏列表
- 响应式：≤760px 隐藏说明文字，导航栏下移避开搜索框

## 本地预览

`data.json` 由 `fetch` 加载，直接双击 `index.html`（file://）会被浏览器拦截，起个静态服务即可：

```bash
python3 -m http.server 8080 --directory .
```

然后打开 http://localhost:8080

## 改数据

只改 `data.json`：

```json
{ "categories": [ { "name": "分类", "subs": [ { "name": "子类", "sites": [
  { "n": "站点名", "u": "https://官网", "d": "一句话简介", "t": "类型" }
] } ] } ] }
```

- `name`：一级分类，建议 2 个字（竖栏宽度固定）
- 子类数量不限；站点数量不限
- 新增/删除站点只动这个文件，页面代码不用改

## 校验链接

```bash
node scripts/check-links.mjs
```

逐个请求所有站点，列出不可达项与重名项；202/401/403/405/429 视为可用（反爬挑战或限流，域名本身没问题）。

## 技术说明

- 单文件页面 `index.html`，数据文件 `data.json`
- 极坐标排布：一级分类在竖栏、二级类目在半径 `(栏宽+R1)/2`、三级站点在 `(R1+R2)/2` 的环带上按扇形展开
- 全屏视图用 `clip-path: circle()` 从点击位置展开
- 无追踪、无第三方脚本、无 Cookie
