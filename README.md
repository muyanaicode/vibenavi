# vibenavi

中国 AI 工具导航（VibeNavi）：单文件 HTML/CSS/JS，收录 20 个中国 AI 工具的官方入口，按对话与推理 / 视频生成 / 图像生成 / 编程与 Agent 分类。

- 打开 `index.html` 即可，无构建、无依赖。
- 内容区是静态 HTML（可被搜索引擎抓取）；JS 只做增强：搜索、同心圆快捷导航、全屏类目视图。
- 同心圆交互：左侧分类 → 悬停展开第一层 → 再悬停展开第二层 → 点击进入该类目工具列表。
- 响应式：≤560px 时左侧栏转为横向。
