# vibenavi

同心圆分类导航：左侧竖向分类栏，悬停展开第一层同心圆，再悬停展开第二层，点击类目全屏展示内容。

单文件 HTML/CSS/JS，无构建、无依赖，打开 `index.html` 即可。

- 分类：对话 / 视频 / 图像 / 编程，共 20 个中国 AI 工具
- 数据：每个工具的真实官网、类型、简介、定价；点击卡片或第三层节点直达官网
- 交互：悬停展开、点击全屏（从点击位置圆形展开）、触屏两段点击、Esc 关闭、深色模式、`prefers-reduced-motion`
- 响应式：≤760px 隐藏说明文字，导航栏收窄

https://boyue.ai

## 改数据

`index.html` 里两处：

- `DATA`：分类 → 子类 → 工具名（决定同心圆结构）
- `TOOLS`：工具名 → `{t: 类型, u: 官网, d: 简介, p: 定价}`（决定卡片内容与跳转）

新增工具：两边同时加一条，名字保持一致。
